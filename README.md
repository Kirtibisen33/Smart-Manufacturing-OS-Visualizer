# OS Algorithm Visualizer – Smart Agriculture & Automated Irrigation System

Operating Systems (5th Sem, Section B) – Assignment No. 3 / Practical No. 09 mini-project.
Problem 9: Smart Agriculture and Automated Irrigation System.

## Modules
1. **CPU Scheduling** – FCFS, SJF, SRTF, Round Robin, Priority (Gantt chart, TAT, WT).
2. **Process Synchronization (Producer–Consumer)** – sensors produce, irrigation controller consumes; bounded buffer with mutex, empty and full semaphores.
3. **Deadlock Avoidance (Banker's Algorithm)** – safety check, safe sequence, resource-request simulation.
4. **Memory Management** – First Fit, Best Fit, Worst Fit with memory map and comparison.

## How to run
Open `index.html` in any web browser. No installation required.
